Comandos Essenciais

git init

cria um repositório Git na pasta atual ou Começa o Git no projeto.

git add .

adiciona todos os arquivos alterados ao Git ou Prepara tudo para salvar.

git commit -m "[mensagem de Commit]

salva as alterações com uma mensagem ou Registra o que eu fiz.

git push -u origin main

envia os arquivos do Git para o GitHub ou Manda meu projeto pro GitHub.

Utilize os comandos com cuidado, utilize espaço, feche as TAGs e matenha a ordem do texto, Alt+shift+F Pra alinhar o texto
