Comandos Essenciais

git init

cria um repositório Git na pasta atual ou Começa o Git no projeto.

git add .

adiciona todos os arquivos alterados ao Git ou Prepara tudo para salvar.

git commit -m "[mensagem de Commit]

salva as alterações com uma mensagem ou Registra o que eu fiz.

git push -u origin main

envia os arquivos do Git para o GitHub ou Manda meu projeto pro GitHub.

git fetch

Verifica se o repositório remoto tem modificações em relação ao local.

git pull

baixa as atualizações do GitHub para o seu PC, puxa as novidades do GitHub.

git clone [link do repositorio]

baixa um repositório inteiro do GitHub para o seu PC, Copia o projeto do GitHub.

git remote add origin [link do repositorio]

iga seu projeto local ao repositório do GitHub, Conecta meu projeto ao GitHub.

Utilize os comandos com cuidado, utilize espaço, feche as TAGs e matenha a ordem do texto, Alt+shift+F Pra alinhar o texto
